# Display Configuration

**Section last revised:** 2026-10-08

## Variables

| Variable | Description | Default value |
|---|---|---|
| {{QUANTITY}} | Number of displays | from the list |
| {{DISPLAY_ID}} | Display control ID | 1 |

## Content

The system is equipped with {{QUANTITY}} display(s) for the conferencing system. The following items are covered in this section:

- Control configuration.

## Control configuration

Make sure to select RS-232 control and to use ID {{DISPLAY_ID}} for each display.
