# DM-NVX Reset

**Section last revised:** 2026-10-08

The procedure below is used to reset NVX encoders and decoders. It must be used if you have forgotten or lost the password to access the unit.

1. Press the Reset button 11 times at 5-second intervals.
2. Wait until the PWR LED is solid green.
3. Hold the Setup button for 5 seconds.
4. Wait about 5 minutes and you will have access to the unit's web interface again.
