# Configuration Moniteurs

**Dernière révision de la section :** 2026-10-03

## Variables

| Variable | Description | Valeur par défaut |
|---|---|---|
| {{QUANTITE}} | Nombre de moniteurs | selon la liste |
| {{ID_MONITEUR}} | ID de contrôle des moniteurs | 1 |

## Contenu

Le système est équipé de {{QUANTITE}} moniteur(s) pour l'affichage du système de conférence. Voici les items couverts dans cette section :

- Configuration pour le contrôle.

## Configuration pour le contrôle

Assurez-vous de choisir le contrôle RS-232 et d'utiliser le ID {{ID_MONITEUR}} pour chacun des moniteurs.
