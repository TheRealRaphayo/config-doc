# DM-NVX Réinitialisation

**Dernière révision de la section :** 2026-10-03

La procédure ci-dessous sert à réinitialiser les encodeurs et décodeurs NVX. Cette procédure doit être utilisée dans le cas où vous auriez oublié ou égaré le mot de passe pour accéder à l'unité.

1. Appuyer 11 fois sur le bouton Reset par intervalle de 5 secondes.
2. Attendre que le voyant PWR soit allumé vert.
3. Maintenir le bouton Setup pour une durée de 5 secondes.
4. Attendre environ 5 minutes et vous aurez de nouveau accès à l'interface web de l'unité.
